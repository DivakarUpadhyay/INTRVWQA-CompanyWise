# 7-Day Study Plan

About 3–4 hours a day. If the interview is sooner, do days 1, 2, 4 and 7.

| Day | Focus | Tasks | Done |
|---|---|---|---|
| 1 | Domain | Read `05-Cheatsheets/IGXL-ATE-Primer.md` twice. Watch 2–3 public Teradyne UltraFLEX / IG-XL videos on YouTube. Write your own 60-second explanation of "what is ATE and what is a test program". | [ ] |
| 2 | Your stories | Read `02-Mock-Interview/Full-Mock-Interview.md` Rounds 1–2. Fill the `[ ]` placeholders with your real numbers. Record yourself answering "Tell me about yourself" and "hardest bug" and listen back. | [ ] |
| 3 | Excel / VBA | Do all drills in `04-Coding-Practice/vba` in a real Excel workbook (Alt+F11). Revise `03-Answer-Bank/02-Excel-VBA-IGXL.md`. | [ ] |
| 4 | Windows debugging | Run the crash/hang/leak demo in `04-Coding-Practice/csharp` (`dotnet run -- crash`, `-- hang`, `-- leak`), capture dumps with ProcDump, and open them in WinDbg. Follow `05-Cheatsheets/WinDbg-Sysinternals.md`. | [ ] |
| 5 | C# / C++ / OOP | `03-Answer-Bank/01-CSharp-CPP-OOP.md` + C# and C++ drills. Write each solution from scratch on paper or in Notepad first. | [ ] |
| 6 | Version control + design | `03-Answer-Bank/04-Version-Control.md`, the design questions in Round 3 of the mock. Practise drawing the ATM / file-database design in 10 minutes. | [ ] |
| 7 | Full mock | Use `06-Practice-App/mock-interview.html` in "Full mock" mode, timed. Re-read `Questions-To-Ask.md` and the logistics checklist. Sleep early. | [ ] |

## Free tools to install for practice

- **WinDbg** (Microsoft Store: "WinDbg") 
- **Sysinternals Suite** (Microsoft Store or `winget install Microsoft.Sysinternals.Suite`)
- **DebugDiag 2.x** (Microsoft Download Center: "Debug Diagnostic Tool v2 Update 3")
- Excel (already installed) with the Developer tab enabled (File → Options → Customize Ribbon → Developer)
